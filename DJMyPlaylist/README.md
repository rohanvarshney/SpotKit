# DJMyPlaylist (WIP)

**DJMyPlaylist** is an upcoming tool in the `SpotKit` suite designed to take an existing Spotify playlist, inspect each song's key signature and BPM, and generate an optimal DJ-ready track ordering for smooth harmonic and tempo transitions.

> **Status**: Work in Progress (placeholder landing page active at `DJMyPlaylist/index.html`).
